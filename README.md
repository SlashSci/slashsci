# SlashSci 斜杠科研

**为 AI 时代设计的文献管理与精读工具。** 把论文读成结构化的全文，批注、笔记、翻译和 AI 问答都在同一处；你的文献始终保存在自己的电脑上。

官网: [slashsci.com](https://slashsci.com)

## 它能做什么

- **结构化全文**: 优先取出版商的结构化全文，保留章节、公式、图表和参考文献，而不是一份难以复制的 PDF。图片可一键换成出版商的高清版。
- **沉浸阅读**: 原文与译文对照，悬停即看关键词和参考文献。专为精读设计的排版，长论文也流畅。
- **批注与笔记**: 划词高亮、框选图片区域，笔记直接引用原文并可跳回出处。语料库收集好句和词汇。
- **翻译与 AI**: 多种翻译引擎和大模型可选，问 AI 时严格依据论文并标出处。密钥保存在你自己的电脑上。
- **一键收藏**: 输入 DOI、arXiv 编号或网址即可导入；浏览器插件能收藏需要登录或订阅才能看的页面。
- **数据属于你**: 文献以 JSON、Markdown 和 XML 保存在本机文件夹，可随时整库导出备份，换电脑一键导入。

目前提供**文献库**（内测中）；Agent 和 Bot 在规划中。

## 下载

[Releases](../../releases/latest):

- **macOS**（Apple 芯片）：`SlashSci-<版本>-arm64.dmg`
- **Windows**（64 位）：`SlashSci-<版本>-x64.exe`

### 安装（内测版尚未签名）

- **Mac**：打开 .dmg，把 SlashSci 拖进「应用程序」。第一次打开如提示「无法验证开发者」，到「系统设置 → 隐私与安全性」点「仍要打开」。
- **Windows**：双击 .exe。出现蓝色的「Windows 已保护你的电脑」时，点「更多信息」，再点「仍要运行」。

有新版本时，应用左侧会出现「新版本」按钮，点一下即可下载。

你的文献保存在自己电脑上的 `SlashSci-Library` 文件夹里。建议隔一段时间在「设置 → 文献库 → 导出整个文献库」备份一次。
