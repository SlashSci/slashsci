# SlashSci 科研不止一面

**SlashSci Library: 为 AI 时代重构的文献管理**

- **块级解构**: 告别 PDF，文献即结构化数据
- **沉浸译读**: 逐句翻译，浮动锚定批注
- **本地优先**: 全部数据存于本机
- **Agent 就绪**: 内置 MCP，模型直接调用

官网: [slashsci.com](https://slashsci.com)

## 核心能力

### 读懂

回到论文本身，而非 PDF 的版面。

- **块级全文解析**：章节、公式、图表与参考文献按结构完整保留；公式以 KaTeX 渲染，引文就地展开并可一键收录
- **沉浸式逐句译读**：译文与语境词汇释义随光标浮现于句侧，原文、译文、对照三种视图即时切换
- **出版级图像**：目录、引文与图表就地展开，插图可一键替换为出版商高清原图

### 沉淀

每一处思考，都锚定在原文之上。

- **浮动锚定批注**：批注沿页边实时排布，以曲线连回原文位置；观点、方法、数据、疑问四色分类
- **双向溯源**：点击批注即定位原文，笔记支持 Markdown 与 LaTeX，引用后一键回到出处
- **语料与术语库**：收录佳句与重点术语，自动附译文、出处与写法解读

### 掌控

数据留在本地，检索尽在指尖。

- **多源收录**：DOI、arXiv、PMCID 或网址一步导入；PDF 优先联网匹配结构化全文；浏览器插件支持需登录的页面
- **期刊指标与智能分类**：中科院分区、JCR、影响因子与被引次数一览；AI 按学科自动归类，中英文全文检索与查重
- **本地优先，为 Agent 而生**：全库以开放格式存于本机，一键导出迁移；内置 MCP 服务，Claude Code 等 Agent 可直接检索

目前提供 **Library**（内测中）；Studio 与 Bot 正在开发。

## 下载

[Releases](../../releases/latest):

- **macOS**（Apple 芯片）：`SlashSci-<版本>-arm64.dmg`
- **Windows**：即将推出

### 安装（内测版尚未签名）

- **Mac**：打开 .dmg，把 SlashSci 拖进「应用程序」。第一次打开如提示「无法验证开发者」，到「系统设置 → 隐私与安全性」点「仍要打开」。

有新版本时，应用左侧会出现「新版本」按钮，点一下即可下载。

你的文献保存在自己电脑上的 `SlashSci-Library` 文件夹里。建议隔一段时间在「设置 → 文献库 → 导出整个文献库」备份一次。
