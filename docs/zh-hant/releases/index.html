0.1.32026-11-28最新

SlashSci Library 0.1.3 內測版，支援 macOS（Apple 晶片）和 Windows（64 位）。從這一版起，內測期間需要啟用才能使用。

改動

  • 內測期間需要啟用才能使用：第一次開啟軟體會顯示啟用頁。填寫收到啟用碼的郵箱，貼上以 SLASHSCI- 開頭的啟用碼，點「啟用」即可進入。
    • 只需啟用一次。啟用在本機完成，不需要聯網。
    • 啟用碼只對對應的郵箱有效。
  • 在「設定 → 關於 → 內測資格」解除啟用後，會回到啟用頁。

新增

  • 啟用頁下方有「還沒有啟用碼？3分鐘申請內測」，點一下直接開啟申請問卷。通過稽核後，啟用碼會發到你申請時填寫的郵箱。
  • 「設定 → 關於 → 內測資格」裡會顯示你的成員編號和啟用碼的發放日期。

0.1.22026-11-28

SlashSci Library 0.1.2 內測版。這一版加入了阿爾法內測資格。

新增

  • 內測資格：在「設定 → 關於」填入郵箱和啟用碼即可啟用，本機驗證，不聯網。成員資訊只存在本機，不進備份。
  • 反饋：傳送反饋時可附帶內測成員編號。

此版本的安裝包已下架：內測從 0.1.3 起需要啟用碼才能使用。

0.1.12026-11-28

SlashSci Library 0.1.1 內測版。這一版修復了 Mac 上「已損壞，無法開啟」的問題，並新增了「反饋」。

新增

  • 反饋：左側欄新增「反饋」按鈕。黃色三角報錯氣泡和介面崩潰卡片裡也有「反饋」，會自動帶上當時的報錯。

修復

  • Mac 下載後提示「SlashSci.app 已損壞，無法開啟」的問題已修復。
  • 桌面版演示筆記時，右側大綱頂部的按鈕點不動；圖片檢視器、對話方塊和右鍵選單的頂部也有同樣的問題。現已修復。

改動

  • 演示時的浮動大綱：點選標題跳轉後，滑鼠移開約半秒才收起。

此版本的安裝包已下架：內測從 0.1.3 起需要啟用碼才能使用。
